# 年轮 · 复利计算器

简体中文 | [English](README.en.md)

设置一次性投入、每月或每个交易日定投和投资年限，查看不同年化收益率下的资产总额、累计投入、收益和逐年对比。

新增「工资与财富自由」：估算中国大陆居民工资个税、个人五险一金、月均到手和年度可支配结余，结合育儿、必要开支、突发医疗支出及定投，查看资产积累和财富自由门槛。

## 打开使用

**在线使用：** [年轮 · 复利计算器](https://compoundlab-nine.vercel.app/)

**直接使用：** 双击 `index.html`，用 Chrome 或 Edge 打开。无需安装依赖或启动服务；网页模式的参数只在当前页面保留。

**作为 Chrome 插件使用：**

1. 在 Chrome 地址栏输入 `chrome://extensions/`。
2. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择这个 `compound-lab` 文件夹。
4. 点击工具栏扩展菜单中的「年轮 · 复利计算器」，打开计算页面。

插件模式会把有效参数自动保存到 `chrome.storage.local`，下次打开恢复。计算不需要网络，没有后端、账户或云同步。仅使用 `storage` 权限，不读取其他网页。

## 怎么计算

- 一次性投入在开始时投资；定投频率可选「按月」或「按天（仅交易日）」。按月可选月初或月末，按天可选每个交易日日初或日末，默认期末投入。定投金额设为 0，可仅计算一次性投入。
- 金额、允许为 0 的费率和数量留空时按 0 计算，输入框保持空白，插件保存计算后的 0。投资年限、交易日、提取率等有正下限的参数仍需有效值；社保、公积金基数留空与填 0 一样，表示跟随月薪。
- 按天默认每年 252 个交易日，可填 1–366 的整数；每年定投额 = 每日金额 × 每年交易日。月金额与日金额分别保留，切换频率不会把二者当作等额预算。旧版已保存的月定投计划可直接恢复。
- 252 天是长期测算假设，近似扣除周末和节假日；可按市场、基金实际情况调整。模型把交易日在全年均匀分布，不逐日匹配日期、各年节假日、临时休市或基金暂停申购。美股实际安排可查 [Nasdaq 休市日历](https://www.nasdaq.com/market-activity/stock-market-holiday-schedule)，境内基金应以自身申购规则为准。
- 支持 1–80 年；除 6%、10%、14.25% 对比情景外，可输入 −90% 到 50% 的自定义年化。
- 默认年化 10%、费用 0.5%、通胀 2%，都是可调整的演示假设，不代表某只基金的实际参数。
- 净年化 `g = (1 + 年化收益率) × (1 − 年化费用) − 1`。
- 有效每期收益率 `r = (1 + g)^(1/N) − 1`：按月 `N = 12`，按天 `N = 每年交易日数`，不直接用年化除以期数；不定投的单笔本金在两种模式下年度收益一致。
- 期末定投：`下期资产 = 本期资产 × (1 + r) + 每期投入`。
- 期初定投：`下期资产 = (本期资产 + 每期投入) × (1 + r)`。
- 今日购买力：`期末资产 ÷ (1 + 通胀率)^投资年数`。
- 内部计算保留浮点精度，界面金额四舍五入到元；大额摘要按亿／万亿显示，完整金额可在逐年表查看。

曲线是假设固定年化的复利测算，不是历史回测或收益预测。历史指数按美元计价；界面金额按人民币展示，未模拟汇率、税费、溢价和跟踪误差。实际定投收益也受涨跌顺序影响。

## 工资、家庭开支与财富自由

- 使用「工资与财富自由」导航进入。该模块沿用上方本金、年限、年化、费用和通胀；独立复利区仍按原有固定定投测算。
- 工资适用中国大陆居民、全年任职、工资薪金的年度估算。年度个税按七档综合所得税率，扣除基本费用 60,000 元、合规个人社保、公积金和填写的专项附加扣除。月均到手包含年终奖的税后金额，是年度到手除以 12，不是每月实际预扣发薪明细。
- 社保默认个人养老 8%、医疗 2%、失业 0.5%，仅为可调整演示；工伤、生育不从个人工资额外扣除。基数填 0 表示跟随月薪，其他数值请填写当地工资单的实际合法缴费基数。当地上下限、上年度平均工资及公积金税前限额不自动查询；手填基数在未来年份也按工资增长率增长。公积金比例各限制在 0–12%，模型假设所填基数与缴存均在当地合法税前扣除范围内。
- 符合条件的年终奖可选择单独计税或并入综合所得。依据当前明确有效期，单独计税仅用于 2027 年及以前，2028 年起自动并入；其他现行税档、60,000 元基本扣除及填写的月专项附加扣除在长期情景中保持名义值不变。起始年为 2026。
- 专项附加扣除填本人已确认可享受的月合计，包含适用的育儿、租房、房贷、赡养老人等，不因填写孩子人数而自动叠加。符合条件的婴幼儿照护／子女教育每孩每月 2,000 元，需按父母实际分配比例填写，同月不得重复扣除。预留医疗资金不作为已发生的大病医疗税前扣除。
- 常规开支包含每月必要支出、每个孩子的月开支与剩余负担年数、其他年度开支；按上方通胀增长。其他收入须填已扣税月收入，持续至测算期末且保持名义值。工资、奖金和缴费基数按工资增长率变化，到填写的领薪年数结束后归零；不推算退休养老金。
- 可将正结余的一定比例用于定投，或沿用上方定投预算并以实际结余为限。定投来自工资结余，不会再次作为额外收入加入资产；未投资结余留在现金中，现金不计利息。工资、奖金和年度税额按月平均分配，工资模块的交易日定投先换算成年预算再按 12 月均分，因此是现金流近似，不模拟奖金到账日或真实交易日。
- 初始现金不含上方已投资本金。公积金包含个人及单位缴存，单独按所填利率增长；其他受限资金仅为填写的现有已归属余额，不估算未来奖励。养老、医保账户不计为可自由投资资产。公积金／其他资金在指定年末转为现金不会增加总资产；公积金解锁后继续按每年可全额提取的情景计算，必须由用户确认符合当地用途、条件及额度；填 0 表示不提取。
- 应急金、医疗储备仍属于现金或投资资产的一部分，只从可用于长期生活的资本中隔离，不作为已经花掉的钱。指定突发开支按今日金额及发生年通胀实际扣除，先动用现金再卖出投资。资金耗尽后显示未覆盖支出累计值，不假设借款或凭空补资；存在未覆盖支出时不宣告达标。
- 自由门槛＝下一年预计常规开支 ÷ 所选年度提取率＋应急储备＋医疗储备＋尚未发生的指定冲击储备。年初使用首年开支，之后每个年末使用下一年开支；金额均为对应年份名义值。只有可用资产达到门槛才算达标，尚未解锁的公积金与其他受限资金只计入总资产。图表与逐年表显示首次达标及持续到期末的达标区间；达标后仍按设定领薪年数积累，不自动模拟达标即退休。

提取率为用户设置的规划假设，不保证任何投资组合可以长期维持。模型不模拟收益顺序、投资变现税费、政策未来变化或疾病概率，也不以「资产达到某个数」保证可以停止工作。新增功能在本地可用；修改代码不代表在线版本已经部署。

规则核对日期：2026-10-25。官方依据：[个人所得税法](https://www.chinatax.gov.cn/n810219/n810744/n3752930/n3752974/c3970366/content.html)、[年终奖计税有效期](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/202308/t468460.html)、[专项附加扣除标准](https://www.chinatax.gov.cn/chinatax/n810341/n810760/c5211366/content.html)、[公积金税前扣除范围](https://shanghai.chinatax.gov.cn/bsfw/nszx/hdfk/202104/t457772.html)。

## 纳斯达克参考

本项目的基准为**纳斯达克 100**，不是纳斯达克综合指数。

- [Nasdaq 40 周年回顾](https://www.nasdaq.com/articles/nasdaq-100-indexr-celebrates-40-years-innovation)：1985-01-31 至 2024 年末的复合年化为 14.25%。原文未明确单列股息口径，本项目不将其另行标为价格或含息回报。
- [Nasdaq 2025 年度回顾](https://www.nasdaq.com/2025-Nasdaq-100-Annual-Reconstitution)：2007 年末至 2025 年末，18 年总回报年化为 16.0%，包含股息再投资。
- [Nasdaq 数据表](https://www.nasdaq.com/docs/index/xndx356c-factsheet)：使用其中 **XNDX 列**，2022 年 −32.38%，2023 年 +55.13%。不要与同页其他策略指数混用。

资料于 2026-10-16 核实，统计区间已分别注明；不自动获取实时行情。6%、10% 是对比假设，14.25% 是历史年化参考，均不保证未来收益。

## 文件说明

- `index.html` / `styles.css` / `app.js`：原生页面、响应式布局、SVG 图表、参数校验与本机保存。
- `calculator.js`：独立复利计算函数，可供浏览器和 Node.js 使用。
- `salary.js` / `salary-app.js` / `salary.css`：工资税费、家庭现金流、受限资产与财富自由规划，以及页面交互。
- `calculator.test.cjs`：金额、费用、负收益、定投时点和输入边界测试。
- `manifest.json` / `background.js` / `icons/`：Manifest V3 插件入口及图标。
- `logo.svg`：页面标志。

验证计算：安装 Node.js 后，在本目录运行 `node --test calculator.test.cjs salary.test.cjs`。
